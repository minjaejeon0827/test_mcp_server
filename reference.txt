04.00. uv - 파이썬 관리에 필요한 단 하나의 툴

uv는 패키지 설치 및 관리와 패키지 빌드 및 배포까지 모두 가능한 궁극의 파이썬 종속성/패키지/프로젝트 관리 툴이다. 기존에 사용되던 pip, pip-tools, pipx, poetry, pyenv, twine, virtualenv 등의 프로젝트, 패키지 관리 툴들을 모두 대체하는 궁극의 툴이다.

Rust로 만든 프로그램답게, 속도 또한 다른 툴들과 비교도 되지 않을 정도로 빠르다. 특히나 이미 다운로드한 패키지의 경우 기본값으로 하드 링크를 이용해 설치하기 때문에 정말 정말 빠른데다 저장 공간도 추가로 필요하지 않다.

uv의 속도를 표현한 다이어그램

설치
설치는 다음과 같은 방식으로 진행할 수 있다.

# 맥OS, 리눅스, WSL
curl -LsSf https://astral.sh/uv/install.sh | sh

# 윈도우
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
pip install uv으로 설치할 수는 있지만 uv는 프로젝트 관리 툴이기에 특정 환경에 구애받게 설치되는 것보단 위의 방법을 이용해서 전역으로 설치하는 것을 추천한다.

가상 환경 만들기
가상 환경을 만드는 명령어는 다음과 같다. python -m venv .venv에 대응하는 명령어이다.

uv venv .venv
이렇게 만들어진 가상 환경은 uv 전용이라던가 하는 것이 아닌, 그냥 pip, poetry에서도 사용할 수 있는 완전히 같은 가상 환경이다. 다만 속도는 venv로 만드는 것에 비해 비교하기 어려울 정도로 빠르다.

파이썬 환경 설정 및 자동 설치
-p <파이썬 버전> 인자를 추가해 파이썬 버전을 지정해 다운로드할 수도 있다.

uv venv -p 3.13
이때 파이썬이 다운로드된 상태가 아니라면 자동으로 파이썬을 다운로드한다.

이때 python-build-standalone이라는 소스에서 파이썬을 다운로드받아 환경에 사용하는데 간편하고 필요한 것들만 다운로드한다는 장점이 있지만 파이썬 설치 파일을 통해 다운로드하면 같이 섶치되는 문서나 IDLE같은 기능들은 따로 다운로드되지 않는다는 특징이 있다. 잘 모르겠으면 그냥 파이썬 공식 웹사이트에서 다운로드받는 것이 속 편하다.

패키지 설치하기
패키지를 설치하는 명령어는 다음과 같다. pip install pytest에 대응하는 명령어이다.

uv pip install pytests
그냥 앞에 uv만 붙이면 되니 굉장히 간단하다. 물론 속도는 pip과 비교하기 어려울 정도로 빠르다.

이렇게 사용하는 것도 가능하지만 개인적으로는 프로젝트를 하나 생성해서 의존성을 관리하는 것을 권장한다.

프로젝트 생성
파이썬은 의존성을 통합적으로 관리하고 패키지를 효율적으로 빌드하고 배포할 수 있도록 한다. 다음의 커멘드를 통해 프로젝트를 초기화할 수 있다.

# 현재 디렉토리를 파이썬 프로젝트로 초기화하고 싶은 경우
uv init .

# NAME이라는 이름의 하위 디렉토리를 파이썬 프로젝트로 초기화하고 싶은 경우
uv init NAME
하드 링크
uv는 패키지들을 다운로드하고 설치할 때 하드 링크를 사용한다. 하드 링크를 사용하면 같은 내용물이 담긴 서로 다른 위치의 파일을 만들 수 있다. uv는 하드 링크를 이용해 서로 다른 가상 환경에서 같은 패키지를 다운로드받더라도 저장 공간을 많이 차지하지 않도록 기본적으로 설정되어 있다.

uvx
uvx는 파이썬으로 제작된 CLI 툴을 사용할 때 사용한다.

예를 들어 uvx black을 사용하면 자동으로 설치에서 실행까지 이루어진다.
